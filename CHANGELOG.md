# Changelog

## [1.0.1] - 2026-09-21

### Changed

- Added scaled toolbar padding and an explicit popup offset so the play/connect control no longer sits too close to the edge of the IDE window.
- Refined the connection chooser with a clearer title, balanced compact dimensions, padded rows, and distinct server/settings icons.
- Updated the plugin package version and documented artifact name from `1.0.0` to `1.0.1`.
